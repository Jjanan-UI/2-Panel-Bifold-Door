## 📌 Project Overview

A complete mechanical design and documentation package for a **top-hung 2-panel bifold door system** — designed for closets, room dividers, and cabinetry where floor space is at a premium.

This is **not a render-only project.** It is a production-ready CAD package: fully detailed part files, sub-assemblies, a verified kinematic motion study, a 15-line Bill of Materials, and an end-user installation guide. Every component — from the U-channel rail to the guide wheel — is modeled, documented, and ready for manufacturing.

## 🛠️ Engineering Features

**🔹 Space-Saving Mechanism**
Folds completely in half, saving up to **50% of the floor space** required by a standard swinging door — ideal for tight interior layouts.

**🔹 Verified Kinematic Motion Study**
A rendered kinematic animation confirms the **90° fold path** and proves zero interference between door panels, hinges, and the U-channel rail across the full range of motion.

**🔹 Adjustable Hardware Design**
Top and bottom bracket assemblies feature **slotted holes** for height and depth adjustment during installation — reducing install time and tolerance stack-up issues.

**🔹 Integrated Soft-Close Spring**
A dedicated door spring assembly (PRT-009) provides controlled soft-close and soft-open motion.
